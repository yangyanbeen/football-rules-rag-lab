## 发现的问题

一次真实多轮探针中，上一轮是拒答时，历史回答会被有意清空；下一轮“那它的表面通常是什么？”的
改写返回 `fallback`，随后模型回答了错误主题的 `L02-01`。这不是 API 会话串线，而是现有多轮问题
改写/无效主题保护仍不足。交付前必须增加“拒答历史不应提供事实、但应保留对象边界”的专项，不能
把这次多轮结果宣布为通过。
