# 公开分发范围

## 允许纳入

项目自有源码、配置示例、Schema、设计与执行文档、来源 URL/署名/许可/修订元数据、稳定 ID/哈希清单及选定的无密钥历史验收报告。代码许可证为 Apache-2.0；Wikipedia 内容及其改编资料保持各自的来源许可，不由代码许可证覆盖。

## 保留本地

原文档规定的 `data/raw/`、`data/processed/`、索引、缓存、模型、虚拟环境、上游 checkout、`.env`、本地账号凭据、用户数据库、会话日志与运行转储不上传。当前未新增全文发布授权或修改原数据规则。

Git 忽略只是第二道保护；推送前仍应核对已暂存文件。原任务三报告中的注册过程是历史记录，实际密码、摘要和账号文件均不在本仓库；该报告引用的本地账号说明/原日志也不公开。部分历史文档含原本机路径，它们是当时操作记录，不是新机器可直接照抄的安装路径。

`PUBLICATION_MANIFEST.json` 标明每个选定原文件的原始哈希与公开副本哈希；未标转换的原文件按字节相同。原本机全量清单和日志留在原工程，本仓库的公开清单另行建立，不覆盖历史清单。

全文将来需要发布时，单独建任务确认来源和第三方内容、署名、修改说明、相同方式共享许可及可分发范围；先形成实际资料清单，再提交单独 PR。

## 后续补交付的版本记录

上文 PUBLICATION_MANIFEST 的字节相同关系指首次 Git 导入的历史快照。后续允许的代码改动与日志追加通过新提交/PR 记录，不改写那份历史快照。当前文件哈希以 `data/manifests/project_file_manifest.json` 为准；原技术/任务文档及 Corpus B0 的冻结约束继续独立核对。本次仅为引用检查增加可选报告路径、追加实验记录并增加交付工具，没有改动原验收标准。
