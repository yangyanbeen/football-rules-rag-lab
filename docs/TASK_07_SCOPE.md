## 测量约定（不改变原指标定义）

- 开发40题中32可回答/8不可回答；测试50题中40/10。检索质量分母只含可回答题；延迟覆盖全部题，分组样本数明确。
- Recall@K沿原文“至少一个人工支持块命中”的题级比例。MRR@10为首个命中排名倒数均值。多支持块覆盖另列，不冒称完整答案正确率；无分级标签不报nDCG。
- 串行并发1，每集合在正式计时前以固定非评测问题预热3次，每题测量3次；第1次排名用于质量计分，所有测量用于延迟，后两次不挑选最好排名。
- 分开报告查询Embedding、向量检索/返回校验、规范化及总检索耗时的P50/P95/均值。P50/P95使用排序后线性插值q*(n-1)，单位毫秒；保留原秒数使结果可复算。
- 总计时包含问题规范化、Embedding本地HTTP及固定模型身份检查、向量检索与其原有来源/距离校验；排除进程/索引加载、预热、写盘、打分和LLM生成。另列启动/整轮wall clock，不能当生产QPS/P95或性能优化结论。
- 标签只在检索完成后的评分/错误分析使用；预测生成接口只接收question_id/question，不能把expected_chunk_ids用于排名。不可回答题仍会返回相似块，不设置拒答阈值；拒答质量留任务十二。
