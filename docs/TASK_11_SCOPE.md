## 数据和固定探针

- 使用已固定的 `BAAI/bge-reranker-base` tokenizer，revision `2cfc18c9415c912f9d8155881c133215df768a70`、tokenizers0.22.1及已核验tokenizer.json；不把其计数称作Ollama内部token数。正文阈值256，不加特殊token；仅超长单元按完整段落贪心合并，保留精确字符区间、不重叠、不改写。超长表格/不可分段落保持原子并明确例外。
- 阈值依据索引文本预算预先固定，不搜索dev/test最优阈值。语料长度探查发现4段超过256，其中点球表1段保持整体；不为制造180→96而强行切短。
- parent按同文档、前两层标题分组，保留成员顺序/标题、规则号及逐成员来源；child与原段精确映射，允许从任一子块回到完整父上下文。
- 数据集 `data/processed/rag_chunks_parent_child.jsonl` 仅本地；公开ID/区间/哈希/来源/字符和token分布。全文与向量不进入公开Git。
- 固定检索探针为不重排Dense80+BM2580、RRF k60、输出10。两个索引都使用精确余弦、相同BGE-M3/CPU配置和原title_body分词参数；原基线使用其已保存向量，未变子块复用同一向量，只有文本改变的子块重新Embedding。
- 精确余弦是本轮两组统一的独立实验后端，不改旧Chroma索引；本轮不把与历史不同后端/重排方案的差别归因于切分，也不声称替换任务十最佳方案。
- 每题一次实际Embedding，同时查询两份独立索引；child与parent_child使用相同种子排名，父块扩展是派生上下文，不伪称第三次模型检索或独立延迟样本。

## 质量、重复与冗余

1. 对照base/child/parent_child。种子Top10转换为上下文后按4096加性token预算装配，父块按首次命中去重，超预算块跳过并记录，绝不悄悄截断表格或条件。
2. 原标签只有原chunk ID，没有子段相关性标注。主指标用保守完整支持口径：前K返回上下文的原字符区间并集覆盖一整条原标注段才计命中；MRR为首次完整覆盖的名次倒数。不得把同源任一片段直接当完整正确证据。
3. 报告同一50题test的Recall@5/10、MRR@10、全部支持覆盖率、分母；同时保留未扩展子块/未限预算/父块扩展结果及上下文token量，说明扩大证据范围的影响。无分级标签则nDCG=null，不做答案LLM评测。
4. 数据重复率为重复正文哈希的多余条数/总条数，父块和子块分开统计，父子天然内容包含不伪称重复错误。上下文冗余率为重复原文字符位置/总原文字符位置，重复量不含标题开销；另报标题/总token开销。父块未去重影子版本只用于冗余诊断，不冒充独立实测或质量优化。
5. 字符/token数均报告均值/中位数/P95/最大值。结构审计覆盖所有字节重组、原始标题/规则、条件例外标记计数、完整表格；抽样为机器结构核对，不伪装专家内容审核。
